# CodyMaster — Codex Installation

## Quick Install

Tell Codex:

```
Fetch and follow instructions from https://raw.githubusercontent.com/tody-agent/codymaster/main/.codex/INSTALL.md
```

## Manual Setup

Top-35 skills are pre-bundled under `.codex/skills/`. Just clone and point Codex at this directory:

```bash
git clone https://github.com/tody-agent/codymaster.git ~/.cody-master
ln -s ~/.cody-master/.codex/skills .codex/skills
```

Skills will be loaded automatically by Codex when relevant.

## Updating

The bundled set is generated by `npm run build:platforms` (35 canonical skills from `skills/profiles/top35.json`). To pull updates:

```bash
cd ~/.cody-master && git pull
```

To rebuild locally after editing source skills:

```bash
npm run build:platforms
```

## Available Skills

The bundle includes 35 curated skills across 5 domains:

- **Engineering**: TDD, debugging, quality gates, test infrastructure, code review
- **Operations**: safe deploy, identity guard, git worktrees, terminal, secrets, i18n
- **Product**: planning, brainstorming, UX/UI, preview, docs, readit, bootstrap
- **Growth**: content factory, ads tracking, CRO
- **Orchestration**: execution, continuity, skill chain, skill index, deep search

For the full 60+ catalog, install the `cm` CLI: `npm install -g codymaster`.

## Usage

Skills activate automatically when relevant. You can also reference them directly by name (e.g., `cm-tdd`, `cm-debugging`).
