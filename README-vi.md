### 🧠 Bộ Não Hợp Nhất: Kiến trúc bộ nhớ 5 tầng + Smart Spine

AI của bạn không chỉ thực thi — nó còn **thấu hiểu và ghi nhớ** qua hệ thống 5 tầng bền vững xuyên suốt phiên làm việc và nhiều thiết bị:

1. **Sensory Memory (Phiên làm việc)** — Ngữ cảnh tức thời của các file đang mở và terminal.
2. **Working Memory (`cm-continuity`)** — Sổ nháp xuyên suốt phiên. AI không bao giờ lặp lại cùng một sai lầm.
3. **Long-Term Memory (`learnings.json`)** — Các bài học được củng cố với cơ chế suy giảm Ebbinghaus TTL thông minh.
4. **Semantic Memory (`cm-deep-search`)** — Tìm kiếm vector cục bộ qua tài liệu bằng `qmd`.
5. **Structural Memory (`cm-codeintell`)** — CodeGraph dựa trên AST. Tiết kiệm đến 95% token cho toàn bộ context codebase.

🦴 **Smart Spine (v4.6+)** — Hệ thần kinh kết nối toàn bộ 5 tầng:

- **SQLite + FTS5** — Tìm kiếm từ khóa xếp hạng BM25, thay thế quét JSON phẳng.
- **Progressive Loading (L0/L1/L2)** & **Smart Brain Router** — Context tải ở mức rẻ nhất đủ dùng qua bộ phân loại task. Tiết kiệm đến **80% token** trên quy trình thông thường.
- **Skill Execution Cache** — Cache FTS5 ấm theo dõi các chuỗi kỹ năng agent thành công. Kết quả khớp bỏ qua vòng lặp LLM tốn token.
- **cm:// URI Scheme** — Kỹ năng yêu cầu context bằng URI, không phải đường dẫn file.
- **Token Budget** — Cửa sổ 200k token được phân bổ sẵn theo danh mục. Không bao giờ tràn ngầm.
- **Context Bus** — Các kỹ năng chia sẻ output theo thời gian thực trong một chuỗi.
- **MCP Server** — 18 công cụ cho Claude Desktop, Goose và mọi MCP client (`src/mcp-context-server.ts`).
- **Intelligent Skill Selection** — `selectTopSkills()` chọn động 2-3 kỹ năng phù hợp nhất cho mỗi chuỗi. Backed by SkillsBench: 2-3 kỹ năng tập trung = **+18.6pp** so với 4+ tải tĩnh.

Kiến thức giá trị cao được đồng bộ hóa với NotebookLM — "Linh hồn" đa thiết bị cho dự án. Tự động tạo podcast và flashcard để đào tạo lập trình viên bên cạnh AI.

### 🧬 Bộ kỹ năng tự phục hồi

CodyMaster có một nhóm skill chuyên dùng để giữ thư viện kỹ năng luôn dùng được khi repo thay đổi.

- `cm-skill-health` kiểm tra sức khỏe thực tế của skill từ tín hiệu đang có: lệch docs, tham chiếu hỏng, retro notes, validate và test gate.
- `cm-skill-evolution` hoàn chỉnh vòng tự trị với 3 chế độ: `FIX`, `DERIVED`, và `CAPTURED`. Sửa đổi, nhân bản và tự động tạo skill mới dựa trên đề xuất của bộ phân tích, kèm bảo vệ chống vòng lặp và backup `.md`.
- `cm-learning-promoter` tìm kiếm trong cơ sở dữ liệu các vấn đề lặp đi lặp lại và tự động nâng cấp chúng thành skill được code cứng (`cm-learned-*`).
- `cm-skill-chain` Auto-Dispatch — điều phối chuỗi tự động với phát hiện task và bàn giao nhiều bước.
- `cm-skill-search` tìm skill phù hợp qua `cm suggest`, skill index và repo search.
- `cm-skill-share` đóng gói skill an toàn giữa các repo và máy khác nhau.

## 🚀 Cài đặt trong 1 phút

**Một lệnh. Wizard hamster thân thiện. 14 nền tảng.**

```bash
npm install -g codymaster && cm
```

Lệnh `cm` khởi chạy wizard onboarding:

1. Phát hiện mọi công cụ AI coding bạn đang cài (Claude Code, Cursor, Antigravity, Codex, OpenCode, Windsurf, Cline, Aider, Continue, Kiro, Amazon Q, Amp, Copilot, Claude Desktop)
2. Hỏi bạn muốn cài kỹ năng cho cái nào (chọn nhiều; công cụ đã phát hiện được tick sẵn)
3. Cho phép chọn profile kỹ năng — `core` (khuyến nghị), `growth`, `design`, `knowledge`, hoặc `full`
4. Cài vào vị trí native của từng nền tảng và in gợi ý bước tiếp theo

Sau wizard bạn có:

```bash
cm install <platform>            # cài hoặc làm mới một nền tảng
cm install --all --profile core  # cài một lần vào mọi nền tảng đã phát hiện
cm doctor                        # nền tảng nào đã cài và kỹ năng nằm ở đâu
cm install --list                # liệt kê mọi platform id được hỗ trợ
```

### Đường dẫn plugin native (vẫn được hỗ trợ)

Nếu bạn muốn cài theo platform cụ thể, tất cả 14 đường dẫn vẫn hoạt động:

- **Claude Code:** `claude plugin marketplace add tody-agent/codymaster && claude plugin install cm@codymaster --scope user`
- **Claude Desktop:** `npx codymaster mcp-serve --install-claude`
- **Cursor (trong Agent Chat):** `/add-plugin cody-master`
- **Gemini CLI / Antigravity:** `gemini extensions install https://github.com/tody-agent/codymaster`

`cm install <platform>` bọc các lệnh này và thêm copy kỹ năng + gợi ý sau cài đặt.

## Dùng với Goose

npm install -g codymaster

## 🎮 Lệnh

Chạy `cm --help` để xem danh sách **theo mã nguồn** (`src/cli/command-registry.ts`). Tóm tắt:

```
cm, codymaster              → CLI
cm status                   → Tóm tắt task & dự án
cm task <cmd> [args...]     → Quản lý task
cm project <cmd> [args...]  → Quản lý dự án
cm deploy <cmd> [args...]   → Deploy / rollback / history / changelog
cm dashboard [start|stop|status|open|url] → Mission Control (mặc định :6969)
cm agent [status|memory|brain|learn]      → Bộ nhớ làm việc / learnings
cm brain                    → Continuity + bước tiếp theo
cm chain <cmd> [args...]    → Skill chain
cm config [key] [value]     → Cấu hình
cm open                     → Mở dashboard trong trình duyệt
cm browse …                 → Browse daemon (Playwright, QA)
cm guardian …               → Kiểm tra lệnh nguy hiểm / đường dẫn
cm sprint …                 → Pipeline sprint + .cm/sprint
cm design-studio [init|status]
cm distro validate …        → Kiểm tra gói skill
```

**Bus, budget, `cm://`, tìm memory:** dùng MCP server — [docs/api/api-reference.md](docs/api/api-reference.md).

**Kỹ thuật:** [engineering-pipeline](docs/workflows/engineering-pipeline.md) · [browse-daemon](docs/browse-daemon.md) · [guardian-hooks](docs/workflows/guardian-hooks.md) · [servers-and-mcp](docs/architecture/servers-and-mcp.md)
