## 🛠️ Enter CodyMaster: The Mission Control for Your Repo

CodyMaster isn't another AI model. It is the **local infrastructure** that sits *around* your codebase, acting as an Operating System for whichever AI agent you choose to use.

We give your agents the three things they desperately lack: **Memory, Rules, and Skills.**

### 1. Long-Term Working Memory
CodyMaster maintains a continuous `.cm/` knowledge base. When your agent wakes up, it reads the memory bus. It instantly knows what you did yesterday, what's broken today, and what the ultimate business goal is.

### 2. The 6-Gate Safety Pipeline
Never let an agent push code straight to production again. CodyMaster enforces strict operational gates:
- ✅ **Test Gate:** No code merges without passing tests.
- ✅ **Security Gate:** Auto-scans for leaked secrets and hardcoded credentials.
- ✅ **Quality Gate:** Enforces your repository's specific architecture and design patterns.

### 3. A Library of 30+ Progressive "Skills"
Stop writing massive prompts. CodyMaster comes with 30+ token-optimized skills. Just tell your agent to use `@cm-tdd` or `@cm-code-review`, and CodyMaster injects the exact step-by-step technical framework the agent needs to succeed.

---

## 🚀 The Path to 10x Productivity (In 3 Simple Steps)

1. **Install the CLI:** Drop `npm install -g codymaster` into your terminal.
2. **Connect via MCP:** CodyMaster instantly connects to Claude Desktop, Cursor, or Goose via the Model Context Protocol (MCP).
3. **Start Vibe Coding:** Run `cm-start` and let the system guide your agent safely from an idea to production code.
