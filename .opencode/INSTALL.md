# CodyMaster — OpenCode Installation

## Quick Install

Tell OpenCode:

```
Fetch and follow instructions from https://raw.githubusercontent.com/tody-agent/codymaster/main/.opencode/INSTALL.md
```

## Manual Setup

Top-35 skills are pre-bundled under `.opencode/skills/`. Just clone and point OpenCode at this directory:

```bash
git clone https://github.com/tody-agent/codymaster.git ~/.cody-master
ln -s ~/.cody-master/.opencode/skills .opencode/skills
```

Skills will be loaded automatically by OpenCode when relevant.

## OpenCode Plugins (Optional)

Plugins extend OpenCode with custom tools and event hooks. They auto-load from:

- `.opencode/plugins/` — Project-level plugins
- `~/.config/opencode/plugins/` — Global plugins

### Install cm-brainstorm-idea Plugin

The `cm-brainstorm-idea` plugin adds a strategic analysis tool directly into OpenCode.

**Option A: Copy plugin file (recommended)**

```bash
# Create plugins directory if needed
mkdir -p ~/.opencode/plugins

# Copy the plugin
cp ~/.cody-master/.opencode/plugins/cm-brainstorm-idea.ts ~/.opencode/plugins/
```

**Option B: Symlink (always latest)**

```bash
mkdir -p ~/.opencode/plugins
ln -s ~/.cody-master/.opencode/plugins/cm-brainstorm-idea.ts ~/.opencode/plugins/
```

**Option C: npm (coming soon)**

```json title="opencode.json"
{
  "plugin": ["@codymaster/cm-brainstorm-idea"]
}
```

### Verify Plugin

After installing, restart OpenCode. You should see:

1. **Custom tool available**: `cm-brainstorm-idea` in your tool list
2. **Auto-detection**: When you say "brainstorm", "what should we improve", or "enhancement", the plugin suggests using the tool

### Using the Plugin

**Direct call:**
```
Use cm-brainstorm-idea to analyze: "Add multi-language support to our app"
```

**Auto-trigger:**
```
What should we improve about our booking system?
```
→ Plugin detects keywords and suggests the brainstorm tool

### Plugin Features

| Feature | Description |
|---------|-------------|
| **5-Phase Analysis** | DISCOVER → DEFINE → DEVELOP → EVALUATE → HANDOFF |
| **9 Windows (TRIZ** | Past/Present/Future × Super/System/Sub matrix |
| **Scoring Matrix** | Tech 25% · Product 30% · Design 20% · Business 25% |
| **UI Preview** | Auto-detects Stitch/Pencil MCP for visual validation |
| **Handoff** | Outputs `openspec/changes/[initiative]/proposal.md` |

## Updating

The bundled set is generated by `npm run build:platforms` (35 canonical skills from `skills/profiles/top35.json`). To pull updates:

```bash
cd ~/.cody-master && git pull
```

To rebuild locally after editing source skills:

```bash
npm run build:platforms
```

## Available Skills

The bundle includes 35 curated skills across 5 domains:

- **Engineering**: TDD, debugging, quality gates, test infrastructure, code review
- **Operations**: safe deploy, identity guard, git worktrees, terminal, secrets, i18n
- **Product**: planning, brainstorming, UX/UI, preview, docs, readit, bootstrap
- **Growth**: content factory, ads tracking, CRO
- **Orchestration**: execution, continuity, skill chain, skill index, deep search

For the full 60+ catalog, install the `cm` CLI: `npm install -g codymaster`.

## Usage

Skills activate automatically when relevant. You can also reference them directly by name (e.g., `cm-tdd`, `cm-debugging`).
