# Design: Astro Landing Page (Hybrid Premium)
Generated by: cm-planning

## Context & Technical Approach
The current VitePress documentation site is functional but lacks a premium, high-conversion visual aesthetic needed to position CodyMaster as a top-tier OS for AI agents. We are migrating the landing page to a dedicated Astro project to enable fast multi-language content creation (i18n via Markdown) while adopting a "Hybrid Premium" design: a mix of Claude-style clean typography and Codex-style technical dark-mode terminals.

### Technical Stack
- **Framework:** Astro (Static Site Generator)
- **Styling:** Tailwind CSS
- **Content Management:** Astro Content Collections (`src/content/landing/en.md`, `src/content/landing/vi.md`)
- **Components:** Astro Native Components (and React if needed) for interactive terminals.
- **Directory:** `/website` (We will initialize inside `/website` for the marketing landing page, keeping VitePress `/docs` for pure documentation).

## Proposed Changes

### Component 1: Typography & Theme System
- Implement a dual-font system: Serif (e.g., Newsreader/Reckless or standard elegant serif) for primary headings, Sans-serif (Inter/Geist) for body.
- Global Tailwind configuration for typography and colors.

### Component 2: The "Amnesia" Hero & Problem Section
- **Hero:** Clean, minimal off-white background. Large serif typography. A simulated "Codex" terminal component floating or integrated below the CTA.
- **Problem Section:** Text-focused area detailing the pain points of AI agents losing context.

### Component 3: 3 Pillars (Interactive Terminal/Code Showcase)
- **Memory, Gates, Skills:** A side-by-side layout. Left side explains the pillar. Right side shows a highly polished, dark-mode terminal UI with syntax-highlighted code or logs.

### Component 4: Content Collections (i18n)
- `src/content/landing/en.md` and `src/content/landing/vi.md` containing the structured text for the landing page.
- Astro pages `src/pages/index.astro` and `src/pages/vi/index.astro` that pull from the collections.

## Verification

- Dark/Light themes render correctly.
- Language switching (en/vi) works.
- Terminal UI components are responsive on mobile.
