## ACTION 1 — Intelligent Skill Selection
**File:** `src/skill-chain.ts`
**Goal:** Dynamic max-3 skill selection per task. Impact: +18.6pp (SkillsBench).

- [ ] 1.1 Add `scoreStepRelevance(taskTitle: string, step: ChainStep): number` function
      - Split taskTitle into tokens (lowercase, strip non-word, filter len≤2)
      - Split step.description into tokens (same)
      - Count overlap; mandatory non-optional steps get +100 base bonus
      - Export for unit tests

- [ ] 1.2 Add `selectTopSkills(taskTitle: string, chain: ChainDefinition, maxSkills?: number): ChainStep[]` function
      - maxSkills default = 3
      - Separate mandatory (optional=false, condition='always') from optional steps
      - If mandatory.length <= maxSkills: include all mandatory + top-scored optional steps to fill up to maxSkills
      - If mandatory.length > maxSkills: include ALL mandatory + log performance warning to stderr
      - Return ordered array: mandatory first (by chain order), then optional by score desc
      - Export function

- [ ] 1.3 Update `createChainExecution()` to call `selectTopSkills(taskTitle, chain, 3)` before mapping steps
      - Replace `chain.steps.map(...)` with `selectTopSkills(taskTitle, chain).map(...)`
      - Pass taskTitle parameter through (already exists in function signature)

- [ ] 1.4 Add warning log when mandatory > 3
      - Print to stderr: `[CodyMaster] Chain "${chain.name}" has ${count} mandatory steps (>3). Consider splitting. (SkillsBench: 2-3 skills = +18.6pp)`

- [ ] 1.5 Write unit tests in `src/skill-chain.test.ts` (or add to existing test file if present)
      - Test: `scoreStepRelevance("fix login bug", { skill: "cm-debugging", description: "Root cause investigation", condition: "always", optional: false })` returns score > 100
      - Test: `selectTopSkills("fix login bug", bugFixChain, 3)` returns exactly 3 steps (all mandatory)
      - Test: `selectTopSkills("", featureDevelopmentChain, 3)` includes cm-planning, cm-tdd, cm-execution (mandatory), excludes cm-brainstorm-idea (optional)
