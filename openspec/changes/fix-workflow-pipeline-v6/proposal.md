# Proposal: Fix Workflow Pipeline v6 — Multi-Platform Skill Sync

Generated by: cm-planning
Date: 2026-05-11

## Qualified Problem

**For:** CodyMaster users across 14 AI coding platforms
**Who:** Need seamless start → brainstorm → planning → execution → QA → deploy workflow
**The:** Skill pipeline is broken due to v6.0 migration gaps
**That:** Skills can't communicate across platforms, TDD not enforced, changelog manual
**Unlike:** v5.x where everything worked end-to-end
**Our approach:** Fix skill sync for all platforms, enforce TDD, automate changelog, add Gemini CLI parallel

### Root Causes:
1. **Skill directory desync** — `build-skills.mjs` only syncs top 35 skills to 3 platforms
2. **Shared helpers inaccessible** — `_shared/helpers.md` not synced to any platform
3. **TDD optional** — Not enforced before execution
4. **No changelog automation** — Manual maintenance only
5. **No Gemini CLI integration** — No parallel execution capability

### Impact if NOT addressed:
- Users on Claude Desktop, Cursor, Codex, etc. can't run full workflow
- AI agents lose context between skill transitions
- TDD discipline breaks (code before tests)
- No audit trail of changes

## Options Evaluated

### Option A: Fix build-skills.mjs (Recommended)
**Approach:** Update script to sync ALL skills + `_shared/` to ALL 14 platforms
**Effort:** S (3-4 hours)
**Risk:** Low

### Option B: Unified Skill Registry
**Approach:** Single source of truth, platforms read directly from `skills/`
**Effort:** M (1-2 days)
**Risk:** Medium

### Option C: Hybrid Approach
**Approach:** Shared skills sync, platform-specific skills keep local
**Effort:** S (4-5 hours)
**Risk:** Low

## Recommendation

**Choose Option A + TDD + Changelog + Gemini CLI:**

1. **Fix build-skills.mjs** — Sync ALL skills + `_shared/` to ALL 14 platforms
2. **Enforce TDD** — Add gate in cm-execution: no execution without tests
3. **Changelog automation** — Git hook + script auto-update on commit
4. **Gemini CLI integration** — `cm parallel` command for parallel execution
