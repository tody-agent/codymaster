# Proposal: Native Agent Installers Migration
Generated by: cm-brainstorm-idea
Date: 2026-04-18

## Why we're doing this
### Qualified Problem
Currently, installing CodyMaster relies heavily on a monolithic 1100-line `install.sh` bash script. This script attempts to manually copy files into hidden directories (`~/.cursor/rules`, `~/.gemini/antigravity/skills`, etc.). Due to differing OS environments, missing directories, and permission issues, the installation is flaky ("lúc đc lúc không") and some agents are hard to install. We need to learn from the `obra/superpowers` repository, which relies entirely on native plugin/extension architectures for each agent instead of a fragile bash script.

### 9 Windows Analysis
| | PAST | PRESENT | FUTURE |
|---|---|---|---|
| SUPER-SYSTEM | Agents were standalone CLIs without extensibility | Agents have native marketplaces and extension systems | Standardized Universal Plugin APIs (MCP, Claude/Cursor plugins) |
| SYSTEM (CodyMaster)| Manual file copy via `install.sh` | Huge fragile `install.sh` + hidden native metadata | Native-only installs, zero bash scripts |
| SUB-SYSTEM | Skills as pure markdown | Skills + CLI tool + Bash deployer | Metadata wrappers (.claude-plugin, gemini.json) point direct to Git |

## What's changing
### Options Evaluated
**Option A: The Superpowers Model (Native Extensions Only)**
- Deprecate `install.sh`.
- Rely entirely on the native package management/plugin systems of AI agents (e.g., `gemini extensions install`, `/add-plugin` for Cursor, `/plugin install` for Claude).
- Update the README to provide platform-specific installation commands instead of the universal curl script.

**Option B: Hybrid Node CLI Installer**
- Wrap the installation logic inside the `codymaster` NPM package (`cm install <agent>`).
- Pro: Replaces bash with cross-platform Node JS filesystem ops.
- Con: Still fundamentally brittle as it manually copies files instead of utilizing the Agent's native update workflows.

**Option C: MCP Server as the Sole Distribution Mechanism**
- Expose all skills purely via MCP tools.
- Con: Some agents don't support MCP well enough yet to dynamically inject large skill texts as system prompts.

### Recommendation
**Choose Option A: The Superpowers Model (Native Extensions Only)**

Why Option A:
1. **Guaranteed Reliability**: Native installers handle their own directory structures, permissions, and updates seamlessly.
2. **Zero Maintenance**: We no longer have to maintain a 1000+ line bash script that needs constant updates whenever an agent changes its local directory structure.
3. **Frictionless Updates**: When we push a change to CodyMaster, users can rely on native commands (like `gemini extensions update`) to fetch changes, rather than re-running a bash script.
